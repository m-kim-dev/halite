## Repository description

A local Markdown reader for project documentation, equations, and diagrams.
Keep editing in your favourite editor; Halite follows your changes.

Repository: [`m-kim-dev/halite`](https://github.com/m-kim-dev/halite). Use **Halite — Markdown reader** in page
titles to distinguish it from other projects called Halite.

## Preview release notes

**Halite 0.2.0 — Linux desktop preview**

Halite gives your project documentation its own reading window. Open an existing
folder, follow relative links, and read Markdown, equations, and Mermaid diagrams
without importing your files.

This preview includes a native file/folder picker, recent projects, light and
dark themes, live refresh, in-document find, and a small example to explore. Documents stay
read-only and local. No Node installation or account is needed for the desktop
package. Remote images and external links can still use the network.

The preview is free to try. Desktop pricing is planned at $19 once after the
installation and reading experience are validated. Purchasing is not open yet.

The published release includes Linux x64 `.deb` and portable archives, SHA-256
files, installation instructions, and the feedback channel. Package checks passed
in Debian 12 / Ubuntu 24.04 containers; real desktop feedback is still needed.

## Tester invitation

I made Halite because I wanted a comfortable way to read a project's Markdown
while continuing to write in my editor. It renders math and Mermaid, follows
relative links, and refreshes when files change.

I'm looking for ten Linux users with real project documentation to try the
desktop preview. It's free during this validation period. I'd especially like
to hear whether you return after the first session, what gets in the way,
