# Halite 0.3.0 — Markdown source view and copying

Read a Markdown document, inspect its original source, and copy it for an email
or another Markdown editor without leaving Halite.

- **Preview / Source** switches between rendered and read-only Markdown. Each
  view remembers its scroll position while the reader is open.
- **Copy Markdown** copies the original document from either view, including
  links, formatting, indentation, and code fences.
- If clipboard access is unavailable, Source opens with its text selected for
  manual copying using Ctrl+C or ⌘C.
- Saved edits refresh both views. Project-tab switches retain the active view;
  navigation and reader reloads start in Preview.
- Documentation now has guides, engineering, releases, business, and marketing
  folders, with compatibility links for published installation docs.

Download the Linux x64 `.deb` or portable `.tar.gz` and its matching `.sha256`.
Verify it with `sha256sum -c FILE.sha256`. See the
[installation guide](https://github.com/m-kim-dev/halite/blob/v0.3.0-preview.1/docs/guides/linux-preview.md).

Before upgrading, run `halite stop` and close the desktop so the next launch
uses the new shared service. Reading preferences and recent projects remain.
Existing tabs/windows, math, Mermaid, live refresh, and document find are included.
There is no automatic updater.

The preview is free, and the source remains MIT licensed. Paid Desktop 1.x is
still planned at US$19 once; checkout is not open.
