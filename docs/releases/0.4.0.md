# Halite 0.4.0 — Neovim integration

The free [halite.nvim plugin](https://github.com/m-kim-dev/halite.nvim) opens
saved Markdown from Neovim in Halite's browser or desktop reader. Use `:Halite`
to open a project tab and `:HaliteFollow on` to follow buffers in already-open
projects. Saving in Neovim refreshes the preview. No paid purchase is needed.

Halite adds `--background` for editor integrations. It navigates only a connected
Markdown project and never launches a window, starts a service, or requests focus.
Project tabs, optional windows, source/copy controls, math, and Mermaid remain.

Download the Linux x64 `.deb` or portable archive with its matching `.sha256`.
Verify with `sha256sum -c FILE.sha256`. Before upgrading, run `halite stop` and
close the desktop so the new command reaches the new service. There is no
automatic updater. Preferences and recent projects remain.
